# Fablerift releases

This repository only hosts the downloadable builds of **Fablerift**, a multiplayer text adventure (MUD).
It contains no source code.

## Download

Open the [latest release](https://github.com/SleepyE5/Fablerift-releases/releases/latest) and download the
bundle for your computer:

| Your computer | Download |
|---|---|
| Windows | `Fablerift-launcher-win-x64.zip` |
| Linux | `Fablerift-launcher-linux-x64.zip` |
| macOS (Apple Silicon) | `Fablerift-launcher-osx-arm64.zip` |

Unzip it and run the installer script inside (`install-windows.ps1`, `install-linux.sh` or `install-macos.sh`).

## Updates

The Fablerift launcher checks this repository each time it starts. When a newer release is here, it asks
before downloading and installing it, and keeps the two previous versions as a backup.

Each release also includes a `.sha256` checksum for the full package.
